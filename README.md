# signate_spectral_moisture
SIGNATEで開催されている近赤外スペクトルから含水率を予測するモデル作成

1. コンペティションの概要
本コンペは、木材の近赤外スペクトルデータから含水率を予測する回帰モデルを作成することがテーマ。
目的: 単なる予測精度の追求にとどまらず、近赤外分光法で長年用いられてきた「ケモメトリクス」的アプローチと、近年発展が著しい「機械学習」アプローチの違いを比較し、それぞれの手法が有効となる前提条件を実践的に検証すること。
データセット: イチョウ、クスノキ、スギ、ヒノキなど全19種類の木材試料。水中に沈めた飽水状態から室温で乾燥していく過程において、重量測定と近赤外スペクトル測定を繰り返し行い取得されたデータ。
評価指標: RMSE（Root Mean Squared Error：平均二乗平方根誤差）

2. 近赤外分光法の簡単な測定の仕組み
近赤外スペクトルは、物質を構成する分子の基準振動の倍音や結合音に由来する光の吸収を捉える手法。
測定方法: 本コンペティションのデータは、フーリエ変換型近赤外分光計を使用し、試料表面から約2 mm離したプローブから近赤外光（10000～4000 cm⁻¹）を照射して測定。
データの取得: 木材表面の数mm程度に侵入し、内部で乱反射して戻ってくる光（拡散反射光）を検出器で捉える。この拡散反射光と、基準となるリファレンス白色板からの反射光を比較することで吸光度を算出する。

3. 近赤外分光法のメリット・デメリット
【メリット】
非破壊・非接触での測定が可能: 対象物を破壊したり、化学的な抽出・分離などの複雑な前処理を行うことなく、そのままの状態（バルク状態）で水分や有機物の成分情報を取得できる。
迅速な測定: サンプルをセットするだけで、短時間かつリアルタイムに近い形での測定が可能
【デメリット】
吸収が弱く、スペクトルが複雑: 近赤外領域の吸収帯は中赤外領域に比べて微弱であり、様々な成分の吸収ピークが幅広く重なり合うため、特定の成分量を単一の波長だけで定量するのが困難
物理的変動（散乱等）の影響を強く受ける: 試料の表面状態（凹凸など）、粒度、密度の違いによる光の散乱の影響を強く受け、スペクトルのベースラインが変動しやすい性質がある。
環境変化への敏感さ: 今回の木材のケースのように、乾燥に伴って試料が収縮することでプローブとの距離がわずかに変化し、それがデータにノイズ（ベースラインの上下など）として影響を与える可能性がある

4. 今回のアプローチ方法
本コンペティションでは、以下の3つの軸に基づいた特徴量設計を行う。
① 水分由来の吸収帯を直接捉える（水分の直接評価） 含水率に強く関係する波長帯である 5000–6000 cm⁻¹ および 6700–7700 cm⁻¹（特に5150 cm⁻¹付近、6900 cm⁻¹付近のピーク）を重点的に利用。波長をそのまま使うだけでなく、帯域ごとのPCA/PLS成分、局所ピークの差分・比率、各種要約統計量を抽出し、活用する。
② ベースライン変動を乾燥進行度の情報として使う（時系列の表現） 近赤外スペクトルにおけるベースラインの上下や傾きの変化は、単なるノイズではなく、木材の乾燥に伴う収縮（測定装置との距離変化）を反映した乾燥進行度の代替指標である可能性が高いと判断。そのため、前処理でこれらを完全に消去してしまうのではなく、以下を明示的な特徴量としてモデルに与え、現在どの乾燥段階にあるかを認識させる。
・生スペクトルに対する主成分分析の第一主成分スコア
・水分の吸収が少ない領域の平均値
③ 木材ごとの差を補助的に表現する（未知樹種への汎化） 樹種によってスペクトル形状や初期含水率は異なりますが、学習データに存在するカテゴリ（species number）に依存しすぎると、未知の樹種に対する汎化性能が低下する。今回の学習データとテストデータの分布を確認すると、２つのデータには異なる樹種が与えられていた。そこで、樹種ラベルを直接使う代わりに、水分帯を除外した領域のPCAスコアや微分スペクトルの形状特徴を用いることで、スペクトルそのものから木材の材質（密度や樹種影響による特性）を表現できると考える。

【運用上の工夫】 乾燥の経過時間を含んでいる可能性が高い sample number は、時系列の代替指標になりえるが、ルール上未知の１サンプルを与えられたときに含水率を予測するというモデルを作成する必要があるので今回は用いないこととする。また、PCAや標準化、PLSなどの前処理は、リークを防ぐために必ずクロスバリデーションのfold内で行い、局所的な精度だけでなく未知樹種への汎化を意識した評価をを行う。
